# Codebook — хадгаламжийн хүүгийн өгөгдөл (4-р долоо хоног)

Шинэчилсэн огноо: 2026-11-16. Цэвэрлэгээний дүрмийг `src/clean_rates.py`-д хэрэгжүүлсэн. Төслийн бүрэн тооцооны дүрэм [`../CALCULATION_RULES.md`](../CALCULATION_RULES.md)-д бий.

## 1. `data/raw/rates_raw.csv` — түүхий өгөгдөл (125 мөр)

| Багана | Утга |
|---|---|
| `row_id` | Мөрийн дугаар (1…125), өөрчлөгдөхгүй |
| `bank_raw` | Банкны нэр, хуудсанд бичигдсэнээр |
| `product_ref` | Бүтээгдэхүүний таних тэмдэг (`deposits.json`-ийн `products[].id`) |
| `product_raw` | Бүтээгдэхүүний нэр |
| `channel_raw` | Үйлчилгээний суваг, хуудсанд бичигдсэнээр. Хоосон бол заагаагүй |
| `term_raw` | Хугацаа, хэвлэгдсэнээр («30 хоног», «30–59 хоног», «3-5 сар», «2 сар 1 хоног – 3 сар», «18 сараас дээш») |
| `rate_raw` | Жилийн нэрлэсэн хүү, хэвлэгдсэнээр («7.20%», «10.50% хүртэл», «9.0%–12.0%») |
| `min_balance_raw` | Доод үлдэгдэл, хэвлэгдсэнээр |
| `payout_raw` | Хүү олгох хугацаа, хэвлэгдсэнээр. Хоосон бол заагаагүй |
| `remark_raw` | Хуудсан дээрх нэмэлт тайлбар |
| `source_url` | Албан хуудасны холбоос |
| `observed_at` | Уншсан огноо (YYYY-MM-DD) |

## 2. `data/clean/rates_clean.csv` — курсын хүснэгт (банк бүр 1 мөр, 12 мөр)

| Багана | Төрөл | Утга ба дүрэм |
|---|---|---|
| `bank_id` | текст | Латин таних тэмдэг: khan, tdb, golomt, xac, state, capitron, bogd, arig, mbank, transbank, chinggis, nibank |
| `bank` | текст | Банкны нэгдсэн нэр (Монголбанкны жагсаалттай тулгасан) |
| `channel` | ангилал | Сонгосон суваг (§4-ийг үз) |
| `m3`, `m6`, `m12`, `m24` | тоо (%) | 3, 6, 12, 24 сарын **жилийн нэрлэсэн хүү**. Жишээ нь `12.2` нь 12.2% гэсэн үг. **Хоосон нүд 0 биш.** Ашиглах боломжтой хүү байхгүй гэсэн утгатай, шалтгааныг нь `note`-д бичнэ |
| `source` | URL | Хүүг авсан албан хуудас |
| `checked` | огноо | Банкны вэбтэй хамгийн сүүлд амжилттай тулгасан огноо |
| `note` | текст | Хугацааг хэрхэн тааруулсан, хоосон нүдний шалтгаан, тооцооны таамаглал. **Таслал агуулахгүй** (`;` тусгаарлагчтай) |

## 3. `data/clean/rates_long_clean.csv` — бүх хүү (давхардалгүй 122 мөр)

| Багана | Утга |
|---|---|
| `term_unit` | `months` (тодорхой сар), `days` (тодорхой хоног), `month_interval`, `day_interval`, `other` (сар+хоног холимог, 1–24 сарын чипэд хамаарахгүй) |
| `term_min`, `term_max` | Мужийн хязгаар, хэвлэгдсэн нэгжээр. `term_max` хоосон бол дээд хязгааргүй |
| `min_inclusive`, `max_inclusive` | 1 бол хил мужид орно, 0 бол орохгүй («2 сар 1 хоног – 3 сар» → min=2, min_inclusive=0) |
| `rate_percent` | Тоон хүү. Муж хэлбэрээр зарласан бол хоосон |
| `rate_qualifier` | Хоосон бол тогтмол хүү. `upper_bound` нь «… хүртэл», `range` нь «a%–b%» |
| `status` | `usable`, `needs_verification`, `excluded`, `unsupported_payout`, `channel_not_selected` (§5-ыг үз) |
| `payout` | `at_maturity` (хугацааны эцэст), `quarterly` (улирал бүр), `unknown` (тодорхойгүй) |
| `channel_selected` | 1 бол сувгийн дүрмээр сонгогдсон |
| `min_balance_mnt` | Доод үлдэгдэл, бүхэл ₮. Хоосон бол тодорхойгүй |

## 4. Ангиллын дүрэм

**Суваг (`channel_raw` → `channel`)**

| Эх сурвалжид бичигдсэн | Ангилал |
|---|---|
| интернэт банк/апп ба салбар | `any` |
| Онлайн, Апп (дижитал) | `online` |
| Салбар | `branch` |
| (хоосон) | `unknown` (тодорхойгүй) |

**Сувгийн дүрэм (бүх банкинд ижил):** банк салбарын хүү зарласан бол түүнийг авна. Зөвхөн нэг суваг зарласан бол (`any`, `unknown` эсвэл зөвхөн `online`) түүнийг авна. Энэ дүрэм зөвхөн ХХБ-д нөлөөлдөг: салбарын 12.2%-ийг авч, онлайны 12.3%-ийг аваагүй.
- **Dashboard-тай ялгаа:** dashboard нь CLAUDE.md-ийн D14 (P2-C) дүрмээр банк бүрийн хамгийн ашигтай бүтээгдэхүүнийг харуулдаг. Тиймээс тэнд ХХБ-ны онлайн хүүг ашигладаг.

**Хүү олгох хугацаа (`payout_raw` → `payout`)**

| Эх сурвалжид бичигдсэн | Ангилал |
|---|---|
| хугацааны эцэст, хугацааны төгсгөлд | `at_maturity` |
| улирал бүр | `quarterly` |
| (хоосон) | `unknown`: «Жишээ тооцоо» гэж тэмдэглээд хугацааны эцэст олгоно гэж тооцно (D15) |

**Хугацааг баганад тааруулах (D1).** Банкны хугацааг дараах дарааллаар хайна. Нэг шатанд олдвол цааш хайхгүй.
1. Яг тэр сар (`months`).
2. Тухайн сарыг агуулсан сарын муж.
3. Тогтмол хүснэгтээр тааруулсан хоног: **m3 = 90, m6 = 180, m12 = 365, m24 = 730 хоног**.
4. Тэр хоногийг агуулсан хоногийн муж.

Хүснэгтээр тааруулсан бүх нүдийг `note`-д «≈ тааруулсан» гэж бичнэ. Ойролцоо хугацааны хүүгээр нөхөх эсвэл интерполяц хийхийг хориглоно.

## 5. Хүүгийн статус ба хоосон нүдний шалтгаан

| `status` | Утга | Хамаарах мөрүүд |
|---|---|---|
| `usable` | Баталгаажсан, энгийн хүүтэй, тооцоонд ашиглана | 88 |
| `needs_verification` | Хүүг дээд хязгаараар («хүртэл») зарласан, сарын ба жилийн хүү зөрсөн, эсвэл бүтээгдэхүүний нөхцөл тодорхойгүй | 16 (Богд, ТХБ 1–2 сар, ҮХОБ 12–24 сар, ХХБ онлайн 24 сар) |
| `excluded` | Нийлмэл хүүтэй (ХасБанк) эсвэл тусгай бүлэгт зориулсан (Чингис хаан — гадаад иргэд) | 8 |
| `unsupported_payout` | Улирал бүр олгодог энгийн хүү. Тооцооны хөдөлгүүр одоогоор дэмжихгүй | 3 (ТХБ 12–24 сар) |
| `channel_not_selected` | Сувгийн дүрмээр сонгогдоогүй (ХХБ онлайн) | 7 |

## 6. Боломжгүй утгын шалгалт

- **Хүүгийн хүрээ:** хүү 0–30%-ийн гадна байвал мөрийг илрүүлж, скриптийг зогсооно. Засахгүй.
- **Хугацааны муж:** `term_max < term_min` байвал мөн илрүүлж зогсооно.
- **Үр дүн (2026-11-16):** хоёр шалгалтад 0 мөр илэрсэн.

## 7. Тооцооны томьёо (эхний туршилт)

Цэвэр орлого = P × r/100 × 0.9

- **P:** хадгаламжийн дүн (10 000 000 ₮).
- **r:** `m12` баганын хүү.
- **0.9:** хүүгийн орлогоос 10% албан татвар суутгасны дараах хувь (ХХОАТ 21.2.4).
- **Дугуйлалт:** зөвхөн харуулахдаа бүхэл ₮ хүртэл дугуйлна (half-up, D10).
