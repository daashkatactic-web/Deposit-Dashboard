# Хугацаатай хадгаламжийн хүүгийн dashboard

Монголын 12 арилжааны банкны төгрөгийн энгийн хугацаатай хадгаламжийг харьцуулдаг нэг хуудастай, статик dashboard. Магистрын хөтөлбөрийн 1-р семестрийн «Хөгжүүлэлтийн технологи» хичээлийн төсөл.

## Төслийн зорилго

- **Dashboard (`index.html`):**
  - Хадгаламжийн дүн, хугацаа, инфляцыг сонгоход банк бүрийн татварын дараах цэвэр өгөөжийг тооцож, эрэмбэлэн харуулна.
  - Хүүг Google Sheets-ийн нийтэлсэн CSV-ээс шууд уншина. Холболт тасарвал `data/clean/rates_clean.csv`-ийг ашиглана.
  - Тооцооны дүрэм: [`docs/codebook.md` §7](docs/codebook.md#7-dashboard-ийн-тооцооны-дүрэм-ба-хамрах-хүрээ).
- **«Өгөгдлийн чанар ба баталгаажуулалт» хэсэг:** CSV шалгалт, 10 000 000 ₮ × 12 сарын цэвэр хүүг Sheets ба JavaScript-ээр бодсон тулгалт, эх сурвалжийн нотолгоо. Энэ нь 4-р долоо хоногийн даалгаврыг (цэвэрлэгээ, codebook, Sheets-ээс CSV унших, тулгалт) dashboard-д нэгтгэсэн хэсэг.

## Цэвэрлэгээний аргачлал

`src/clean_rates.py` хоёр хувилбарыг өөрчлөгдөхгүй оролтоос дахин үүсгэнэ:

1. **v1 (2026-11-16, архив):** `rates_raw.csv` → `data/clean/archive/v1_2026-11-16/`. Скрипт энэ хавтсыг үүсгэнэ, GitHub-д нийтлэгддэггүй. Алхамууд:
   - банкны нэрийг нэгтгэнэ;
   - сувгийг ангилна;
   - давхардлыг хасна (3 мөр);
   - «7.20%» хэлбэрийн хүүг тоо болгоно;
   - хугацааны 8 хэлбэрийг задлана;
   - 0–30%-ийн мужийг шалгана;
   - `deposits.json`-той бүгдийг тулгана;
   - D1 хүснэгтээр m3/m6/m12/m24 баганад тааруулна.

   Дүрмүүд нь [`docs/codebook.md`](docs/codebook.md)-ийн хавсралтад бий.
2. **v2 (2026-11-25, одоогийн):** Sheets-ийн snapshot → `data/clean/`. Скрипт хүүг сонгож засахгүй, судлаач Sheets дээр шийдсэнийг шалгаж баримтжуулна:
   - 11 баганын нэр, төрөл, мужийг шалгана;
   - `net12`-ийг дахин бодно;
   - нүд бүрийг v1 ба түүхий судалгааны мөртэй тулгана;
   - v1 → v2 өөрчлөлтийг `cleaning_log.csv`-д бүртгэнэ.

Хоосон хүүг хэзээ ч 0 болгохгүй. `data/raw/` болон `data/snapshots/`-ийг гараар засахгүй.

## Программыг ажиллуулах

Хуудсууд JSON/CSV файлыг `fetch`-ээр уншдаг. Тиймээс файлыг давхар дарж (`file://`) нээвэл ажиллахгүй, локал HTTP сервер хэрэгтэй:

```bash
python -m http.server 8765 --bind 127.0.0.1
```

| Хаяг | Агуулга |
|---|---|
| http://127.0.0.1:8765/index.html | Dashboard. Хүүг Google Sheets-ээс live уншина. `?csv=<нийтэлсэн CSV холбоос>` параметрээр эх үүсвэрийг түр сольж болно. |
| http://127.0.0.1:8765/tests/tests.html | Тооцоо, өгөгдөл, Sheets уншилтын тестүүд |

Өгөгдлийг дахин цэвэрлэх:

```bash
python src/clean_rates.py                 # data/clean/-г (v1 архив + v2) дахин үүсгэнэ
python src/clean_rates.py --check         # дахин үүсгэсэн үр дүнг data/clean/-тэй байт бүрээр харьцуулна (ижил бол 0)
python src/clean_rates.py --compare-live  # Google Sheets-ийн одоогийн CSV-г rates_clean.csv-тэй мөр бүрээр тулгана
python src/clean_rates.py --fetch         # шинэ огноотой snapshot татна (байгаа файлыг дарж бичихгүй)
```

`--check` нь нийтлэгдэх 3 файлыг (`rates_clean.csv`, `source_check.csv`, `cleaning_log.csv`) заавал харьцуулна. `.gitignore`-д орсон файлууд байхгүй бол тэдгээрийг алгасна.

**VS Code Live Server:** **Go Live** товчийг дарахад сервер http://127.0.0.1:5500 дээр асна.

## Sheets болон JavaScript-ийн тооцооллын тулгалт

- **Томьёо:** `net12 = 10 000 000 × (m12 / 100) × 0.9`. 10% татварын дараах энгийн нэрлэсэн хүүгийн жишиг тооцоо.
- **Үр дүн:** dashboard-ийн «Өгөгдлийн чанар ба баталгаажуулалт» хэсэгт Sheets-ийн `net12`-ийг JavaScript-ийн тооцоотой тулгахад 12/12 банк PASS, хамгийн их зөрүү 0 ₮ (Chromium, 2026-11-25). Python скрипт ч мөн адил 12/12, 0 ₮.
- **Хамгийн өндөр, бага:** Капитрон банк 1,278,000 ₮; ХасБанк 990,000 ₮.
- **Тооцооны логик тусдаа:** энэ жишиг тооцоо нь dashboard-ийн эрэмбийн тооцооноос тусдаа логиктой (`js/benchmark.js`). Иймээс эрэмбээс хасагдсан банкууд ч энд бодогдоно.
- **Fallback:** Sheets-ээс татаж чадахгүй үед хуудас локал файлыг ашиглаж, тулгалтыг «NOT VERIFIED» гэж харуулна. Энэ горимд PASS харуулахгүй.

## Судалгааны хязгаарлалт

- **Шинэ хүүнүүдийн баталгаажуулалт:**
  - v2-ийн 22 тоон нүд өмнөх судалгааны баримтад байхгүй (ХААН, Голомт, Капитрон, М банкны онлайн хүү; ХасБанк; Богд).
  - Нотолгоо нь зөвхөн Sheets-ийн `source`/`checked`. Дэлгэцийн зураг гэх мэт файл-нотолгоо репод байхгүй.
  - 20 нүдний хүү тэнцүү ч суваг өөр байгаа (`unknown` → `any`).
- **`net12` нь жишиг тооцоо.** Дараах зүйлсийг тусгаагүй:
  - нийлмэл хүү (ХасБанк);
  - шаталсан хүү (Богд: 2 саяас дээш 13.5%);
  - нэмэлт хоног (М банк);
  - үр ашигт хүү (Тээвэр 14.75%);
  - хоног тоолох арга;
  - инфляц.
- **Судалгааны горим:**
  - Dashboard нь Sheets-ийн хүүг «Судалгааны өгөгдөл — баталгаажаагүй» шошготойгоор эрэмбэлнэ. Баталгаажсан горим биш.
  - Sheets-д зөвхөн 3, 6, 12, 24 сар байгаа тул 1, 9, 18 сард эрэмбэ хоосон.
  - Богд банкны 12 сарын хүү (шаталсан) эрэмбэд ороогүй.
  - М банкны нэмэлт хоног болон дүнгийн нэмэгдлийг тооцоогүй.
- **Мэдээллийн огноо:** хүү 30 хоногоос хуучирвал «Шинэчлэх шаардлагатай» гэж тэмдэглэгдэнэ. Банкны вэбээс автоматаар татах ажиллагаа байхгүй.
- **Хөтчийн хамрах хүрээ:** зөвхөн Chromium дээр туршсан.
- **Санхүүгийн зөвлөгөө биш:** энэ бол хичээлийн судалгааны төсөл. Бодит нөхцөлийг банкнаас шууд лавлана уу.

## Хүү өөрчлөгдвөл

Шинэчлэлийг гараар, хүн хянаж хийнэ.

1. Банкны албан хуудсыг нээж, шинэ хүүг Google Sheets-ийн `clean` хуудсанд оруулна. Нотолгоогоо (огноо, холбоос) хадгална.
2. `python src/clean_rates.py --fetch` командаар шинэ snapshot татаж, `SNAPSHOT` тогтмолыг шинэчилнэ.
3. `python src/clean_rates.py`, дараа нь `--check`-ийг ажиллуулна. `quality_checks.csv`-д FAIL байхгүй эсэхийг шалгана.
4. Dashboard нь Sheets-ийг шууд уншдаг тул хүү автоматаар шинэчлэгдэнэ. Харин `source_check.csv` нь snapshot-ын утгатай харьцуулдаг, иймээс шинэ утга «NOT VERIFIED (snapshot-оос өөр)» гэж харагдана. Шинэ snapshot-оор скриптийг дахин ажиллуулж, `tests/tests.html`-ийг шалгана.
5. Хүү 3/6/12/24 сараас өөр хугацаанд нэмэгдвэл (шинэ багана) `js/sheets.js`-ийн `SHEETS_COLUMNS` болон шалгалтыг шинэчилнэ.
6. Банкны тусгай нөхцөл (шаталсан хүү гэх мэт) нэмэгдвэл `js/sheetsdataset.js`-ийн `SHEETS_RATE_HOLDS`-д бүртгэнэ. Эрэмбэд таамгаар бүү оруул.
