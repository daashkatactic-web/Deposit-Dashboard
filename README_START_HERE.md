# Deposit Dashboard — Claude Code эхлүүлэх заавар

1. `Deposit-Dashboard` нэртэй локал хавтас үүсгэнэ.
2. Энэ багц дахь **5 үндсэн `.md`** файлыг тэр хавтасны root-д хуулна: `CLAUDE.md`, `PROJECT_SPEC.md`, `DESIGN_SYSTEM.md`, `CALCULATION_RULES.md`, `DATA_SOURCES.md`.
3. Claude Desktop → Code хэсгээр тэр хавтсыг нээнэ.
4. Эхний хүсэлт: “Read CLAUDE.md and all four referenced specification files. First check for contradictions and summarize project principles in Mongolian. Do not write application code yet. Suggest a scoped Phase 1 plan.”
5. Баримт бичгийг шалгасны дараа л HTML/CSS/JS scaffold үүсгэж эхэлнэ.

Санамж: Энэ багц дахь хүүгийн мэдээлэл бүрэн баталгаажсан бодит JSON биш. 10%-ийн татвар нь албан хууль, татварын нөхцөлийн эцсийн шалгалт шаардсан төслийн таамаглал. Бүх банкны 1–24 сарын бүтээгдэхүүн бодитоор байх албагүй.
